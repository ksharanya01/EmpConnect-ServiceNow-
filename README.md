# EmpConnect - ServiceNow Application

## Overview
EmpConnect is a custom scoped ServiceNow application that automates 
employee onboarding and query management workflows.

## Features
- Auto-creates 4 onboarding tasks on new employee record creation
- Auto-prioritizes queries based on category
- Role-based access control
- Real-time dashboard with 4 reports

## Tech Stack
- ServiceNow Flow Designer
- Business Rules (GlideRecord)
- Script Includes (Class.create())
- Client Scripts & UI Policies
- Platform Analytics Dashboard

## Certification
Built by a ServiceNow CSA & CAD Certified Developer

## Installation
Import the update set XML into your ServiceNow instance.
